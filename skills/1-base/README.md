# 1 · Base

A base que todas as outras skills usam. O instalador coloca ela junto sempre, você não precisa pedir.

**Instalar só este grupo:** `bash skills/instalar.sh ~/meu-canal base`

### `motor`
O motor de edição: instala o que precisa, junta e normaliza a voz, acha o tempo de cada palavra usando o seu texto, monta o fundo, renderiza a legenda, mistura a música e confere o vídeo final.

<sub>Pasta: [`motor/`](motor/) · Precisa de: Node.js 20+, Python 3.10+, ffmpeg</sub>
