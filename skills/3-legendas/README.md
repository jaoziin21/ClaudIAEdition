# 3 · Legendas

Cada uma é um estilo completo de legenda animada. Dá para trocar a fonte de qualquer uma (`/fontes`) e somar os efeitos que quiser.

**Instalar só este grupo:** `bash skills/instalar.sh ~/meu-canal legendas`
